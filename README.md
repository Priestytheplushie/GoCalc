# GoCalc
A simple CLI calculator tool because why not? 

## QuickStart
Run the code using the following: 
```powershell
git clone https://github.com/Priestytheplushie/GoCalc.git 
cd GoCalc 
go run main.go
``` 

## Usage 
GoCalc supports binary operations, such as 5+3, 2^3, and 10 % 3, including the operators +, -, *, / ^, %, as well as Unary operations, such as sqrt, abs, sin, including sqrt, abs, sin, cos, tan. Type `exit` or `quit` to leave

```powershell
Welcome to GoCalc
-----------------------------------------
Binary ops (e.g., 5 + 3, 2 ^ 3, 10 % 3): +, -, *, /, ^, %
Unary ops  (e.g., sqrt 16, abs -5, sin 90): sqrt, abs, sin, cos, tan
Type 'exit' to quit

<GoCalc> 
```
